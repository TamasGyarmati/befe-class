JavaScript nyelvi jellemzői
- high-level
	- nincs erőforrás/memória-kezelés
	- nem CPU közeli nyelv
	- magasabb absztrakciós szint

- garbage-collected
	- van egy mechanizmus amely figyeli az erőforrásokat és felszabadítja a nem használt erőforrásokat

- prototype-based
	- hasonlóan C#-hoz, ahol minden az Objects-ből származik le, itt minden a Prototype-ból (kicsit különlegesebb objektum)

- object-oriented

- multi-paradigm
	- I. Procedurális, OOP, Funkcionális paradigmákat is támogatja
		- Funkcionális | pl.: tömb metódusok "[].filter(...).map(...).reduce(...)"
	
	- II. Imperatív : hogyan? | Deklaratív : mit szeretnénk?
		- Deklaratív | pl.: Angular -> ngfor, @for

- interpreted or JIT (Just-in-Time)

- dynamic
	- nem kell típust meghatározni
	- let a = 100 -> a = "fa" engedélyezett

- single-threaded
	- a végrehajtás egyszálon tud működni
	- aszinkronitás != párhuzamos programozás

- first-class functions
	- a függvényeket változókban ellehet tárolni / használni őket
	- callback függvények (függvény amely egy másik függvényt hív / vesz át?)

- non-blocking event loop concurrency model

var változó
- Console.WriteLine(a); -> int a = 100 -> hiba
- console.log(a); -> var a = 10; -> elérhető de undefined -> jelenség neve : hoisting
	- var típusú változók a scope legelejére fel 'hoist'-olódnak
	- var a; -> console.log(a); -> a = 10;

- Temporal Dead Zone (TDZ)
- var -> function vagy block scope
- let, const -> block scope

JavaScript Runtime
- JS Engine -> JS kód végrehajtás (V8 google (node), spidermonkey (firefox)) -> C++-ban írt, implementálja az ECMAScript (JS szabvány) és WebAssembly-t
	- callstack [utasítások azaz execution context-ek] (VS Code debugging)
		- LIFO elv

	- heap [objektumok]
		- primitív típusok -> callstack-en tárolódnak
		- komplexebb objektumok -> heap-en tárolódnak
		- Garbage Collector tisztítja

- Web APIs -> nem a JS része, a böngésző biztosítja a nyelv számára
	- DOM, Fetch API, Timers

- Callback Queue (Microtask queue, Task queue)
	- FIFO elv
	- történik egy utasítás -> a callstackbe kerül (pl. Fetch API hívás) -> átkerül a callback queue-ba -> történik egy event loop -> visszakerül a callstack-be
	- Promise elv
