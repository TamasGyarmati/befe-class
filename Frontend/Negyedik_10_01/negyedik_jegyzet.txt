- API Integration
    + HttpClient, konstruktor DI
    + this.http.[get/post/put/delete]<any>("URI", [post esetén entity]).subscribe(x => ...)

- Token Based Auth Integration
    + BE-től vissza jön a Token, és a FE request-et Tokennel együtt adja le, hogy authorizálja magát
    + Interface generálás
        + ng g interface [interface_name]
        + Mikor kell interface (van olyan típus is, hogy "type") vs. class Angularban?
            + Interface prefferált
    + Authorizálás frontenden: canActive (bevan-e jelentkezve?) + isLoggedIn (van-e localStorage-ban token?)
    + ngIf-re rárakjuk, hogy eggyes dolgok ne látszódjanak + route-on belül van kezelve, hogy ne legyen elérhető sem 
        + { path: ..., component: ..., canActive: [AuthService] }
